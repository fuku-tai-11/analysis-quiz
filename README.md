# 解析のアトリエ

大学数学の微分積分を、計算・証明・概念の3つの視点から学ぶ日本語クイズアプリです。**保存済みの54問から練習やまとめテストを自動作成します。APIキーもAIサービスの利用料も必要ありません。**

## 学習内容

- 大学基礎・標準・応用の3段階。初期設定は「標準」。
- テーマは極限・連続、微分・テイラー、積分の3つ。
- ε–δ、実数の完備性、一様連続、テイラーの剰余項、リーマン積分、広義積分、一様収束などを扱います。
- 高校範囲だけの微分・積分の公式練習は含みません。
- 各分野・難易度・テーマの組合せに2問ずつ、合計54問を収録しています。

## まとめテストの作り方

1. 学習モードで「まとめテスト（3分野）」を選びます。
2. 難易度・テーマ・問題数（3・6・9問）を選びます。
3. 「学習をはじめる」を押します。

計算・証明・概念を同数ずつ選び、同じテスト内では問題が重複しません。「すべて」のテーマなら3テーマも同数になるように選びます。毎回ランダムに選ぶため、別々のテストでは同じ問題が出る場合があります。

条件に合う問題が指定数より少なければ、収録されている全問を出題し、その旨を画面に表示します。たとえば標準・積分のまとめテストには6問あります。

提出後に模範解答、段階的な解説、具体例、注意点を確認できます。通常の練習ではヒントも使えます。**記述・証明答案の自動採点はありません。** 模範解答との比較と確認項目による自己評価方式です。

## パソコンで動かす

Node.js 22以降（24以降を推奨）が必要です。このフォルダーをターミナルで開き、次を実行します。

```powershell
npm install
npm start
```

ブラウザーで http://127.0.0.1:3000 を開きます。終了するときはターミナルでCtrl+Cを押してください。

APIキーの取得、`.env` の作成、外部AIサービスの契約は不要です。以前の有料API連携は取り除きました。答案は外部に送信せず、この画面を開いている間だけ保持します。再読み込みすると消えるため、必要なら終了画面の「復習メモを保存」を利用してください。

## 料金と通信

テスト作成・問題の表示・解説の表示で外部AIサービスを呼び出すことはなく、API利用料は発生しません。アプリはブラウザー内で動き、数式ライブラリーとフォントもアプリと一緒に配信します。インターネット接続料金や、将来別途選ぶ有料ホスティング等はこの説明に含みません。

新しい問題は利用のたびにAIが作るのではなく、収録データを更新して追加します。

## 静的サイト用のファイルを作る

```powershell
npm run build
```

`dist/` に配信に必要なファイルだけを作成します。GitHub Pagesなど静的ファイルを置ける環境でも使える構成です。APIサーバーやVercelは不要です。今回の作業はGitHubへのソースコード保存までで、サイト公開の設定はしていません。

`dist/` は生成物なのでGitHubには保存しません。数式は [KaTeX](https://katex.org/) を使用し、ライセンスも生成物に含めます。HTMLをダブルクリックする方法ではなく、HTTPサーバーで配信してください。

## 問題や画面を変更する

| ファイル | 役割 |
| --- | --- |
| `lib/bank.mjs` | 最初の27問と問題一覧の結合 |
| `lib/extra-bank.mjs` | 追加27問・詳しい解説・問題ごとの確認項目 |
| `lib/quiz.mjs` | 条件に合う問題をバランスよく選ぶ処理 |
| `public/index.html` | 画面の構造 |
| `public/app.js` | 学習・まとめテスト・復習の画面操作 |
| `public/math.js` | 積分・指数・分数の数式表示 |
| `public/style.css` | 色やレイアウト |
| `server.mjs` | 手元での確認用の静的ファイル配信 |
| `scripts/build.mjs` | 静的サイトの生成 |

問題を増やす場合は既存の書式に合わせて問題データを追加してください。`id` は全問で一意にし、数式は `\( ... \)`（文中）または `\[ ... \]`（独立行）で囲みます。

## 動作確認

```powershell
npm test

```

全54問の分類と数式、出題条件、まとめテストの分野・テーマのバランス、問題の重複、外部API接続の除去、配信するファイルの範囲を検証します。
