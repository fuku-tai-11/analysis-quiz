# 解析のアトリエ

大学数学としての微分積分を、計算・証明・概念の3つの視点で学ぶ日本語クイズアプリです。高校範囲だけの微分・積分の公式練習は含みません。初期設定は「標準」です。

## できること

- 難易度は「大学基礎・標準・応用」。ε–δ、上限と収束、平均値の定理、テイラーの剰余項、リーマン積分、広義積分、一様収束などを扱います。
- 収録問題27問（3分野 × 3難易度 × 3テーマ）。条件に合う収録問題が指定数より少なければ、利用できる全問を表示します。
- まとめテストは3分野を混ぜて出題し、提出後に解説を表示します。
- ヒント、段階的な解説、具体例、注意点、理解の確認、自己評価、復習メモのダウンロード。
- APIキー設定後は、選んだ条件でAIが新しい問題を生成します。実際に生成に失敗した場合はエラーを表示し、収録問題への自動切り替えはしません。

証明や記述答案の自動採点はありません。自己評価で模範解答と照合します。AIの数学的正確性も保証されません。収録問題・AI問題とも、必要に応じて教科書と比較してください。

## まず自分のパソコンで動かす

必要なもの：Node.js 22以降（Node.js 24以降を推奨）。数式表示にはKaTeXを使用します。初回は `npm install` で必要なパッケージを入れてください。

1. このフォルダーをターミナルで開きます。
2. 次を実行します。

```powershell
npm install
npm start
```

3. ブラウザーで http://127.0.0.1:3000 を開きます。
4. 終了するときはターミナルで Ctrl+C を押します。

収録問題はAPIキーなしで利用できます。答案はメモリー上だけに保持し、再読み込みすると消えます。必要な記録は、終了画面の「復習メモを保存」で残してください。

## AI出題を有効にする

AI出題にはOpenAI APIの利用設定とAPIキーが必要です。実行に伴う料金はAPIアカウント側で確認してください。

1. `.env.example` をコピーして `.env` というファイルを作ります。
2. `.env` の `OPENAI_API_KEY=` の後ろにAPIキーを入力します。
3. 必要なら `OPENAI_MODEL` を、自分のアカウントで利用できるStructured Outputs対応モデルへ変更します。
4. サーバーを停止して `npm start` で再起動します。
5. 画面の出題方法で「AIがその場で作成」を選びます。

APIキーはチャットに貼り付けず、`.env` にだけ記入してください。`.env` は `.gitignore` でGitHubへの登録対象から除外しています。キーはサーバー側だけで使用し、ブラウザーに渡しません。

AI連携は公式の [Responses API / Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses) に基づきます。返却形式に加え、問題数・分野・難易度・テーマ・解説の存在をサーバーで確認します。これらは数学の正しさを自動保証するチェックではありません。利用するモデルやAPIの設定によっては生成できないことがあります。

## GitHubへ保存する

GitHubはソースコードを保存・共有する場所です。このアプリのAI機能には、別途Node.jsサーバーの実行環境が必要です。GitHub Pagesだけではこのサーバー部分は動きません。

このフォルダーはすでにGitリポジトリです。GitHubで空のリポジトリを作り、ターミナルで次を実行してください（URLを自分のものに置き換えます）。

```powershell
git add .
git commit -m "大学解析学クイズアプリを追加"
git remote add origin https://github.com/YOUR-NAME/analysis-quiz.git
git push -u origin HEAD
```

すでに `origin` が登録されている場合は追加コマンドを実行せず、`git remote -v` で送り先を確認してください。

この試作版はローカル利用用で、サーバーは `127.0.0.1` だけに接続します。不特定多数向けの公開には、ホスティングに合わせた起動設定、認証、利用者ごとの回数制限、API予算上限が必要です。現在は同時生成1件・生成開始の間隔15秒というローカル用の簡単な制限のみです。GitHubへのコードの保存と、アプリをインターネット上で動かすことは別です。Vercelなどへの公開用設定・デプロイはまだ行っていません。

## 動作確認

```powershell
npm test
```

問題の分類、出題条件、総合テストの3分野、APIルート、不正入力の拒否、AI応答処理を検証します。AI応答はテスト用データに置き換え、料金を発生させずに連携処理を確認します。実際のAI生成には自分のキーでの接続確認が別途必要です。

## 数式表示

積分の上下限、指数・添字、分数はKaTeXで組版します。ライブラリーと数式フォントはサーバーから配信するため、数式表示用の外部CDNには依存しません。既存の収録問題は表示時に変換し、AI出題はLaTeX形式の数式を使います。新しい問題の数式は `\( ... \)`（文中）または `\[ ... \]`（独立行）で囲んでください。導入方法は [KaTeX公式ドキュメント](https://katex.org/docs/browser) に基づきます。
